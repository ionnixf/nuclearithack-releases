# Инструкция жюри — Android x86_64, RC1

Комплект полностью автономный: APK, все 7 файлов speech/LLM-моделей,
лицензии, контрольная речевая запись и SHA-256. Для установки нужен компьютер
с Python 3.11+ и Android platform-tools (`adb` в PATH). Интернет, Gradle,
кэш разработчика и дополнительные загрузки не нужны. На устройстве нужно
не менее 2 ГБ свободного места. Проверенный стенд: API 35, x86_64, 4096 МБ RAM,
2 vCPU. Другие ABI этим APK не поддерживаются.

1. Распакуйте `nuclear-rc1-x86_64.tar.gz`. Запустите чистый AVD Android 15
   (API 35, Google APIs x86_64), RAM **4096 МБ**, 2 vCPU, через Cold Boot / Wipe Data.
   Узнайте serial командой `adb devices`. Для нестандартного ADB-сервера
   добавьте к установщику `--adb-port PORT`.
2. Из распакованного каталога выполните **одну команду**:

   ```bash
   python3 install.py --serial emulator-5554
   ```

   Замените serial своим. Установщик проверяет все SHA-256 до установки,
   устанавливает подписанный APK, **очищает приватные данные приложения**,
   копирует и проверяет все модели на устройстве, кладёт контрольный WAV в
   `Download/Nuclear`, включает авиарежим, отключает Wi-Fi/мобильные данные
   и запускает приложение. Дождитесь `SUCCESS`. Протокол сохраняется рядом
   в `installation-ДАТА-ВРЕМЯ.txt`. Этот demo APK подписан Android debug-ключом:
   установщик использует штатный `run-as` для приватного хранилища.
3. Сеть оставьте отключённой. Нажмите **«Выбрать WAV»**. В системном пикере
   откройте меню → **Downloads** → **Nuclear** → **jury-speech.wav**.
   Это синтетическая русская речь eSpeak NG, исходный текст и происхождение
   в `samples/PROVENANCE.md`; эталон результата в приложение не включён.
   Можно выбрать собственный PCM16 WAV: mono/stereo, 16/44.1/48 кГц.
4. Дождитесь **«Обработка завершена»** и непустых реплик. Раскройте **«Лог стадий»**:
   должны пройти декодирование, диаризация, ASR, LLM и сборка результата.
   На эмуляторе обработка может идти дольше длительности записи.
5. Нажмите **«Экспортировать JSON»**, в системном окне сохранения выберите Downloads
   и имя `jury-transcript.json`, нажмите **SAVE** / **Сохранить**.
6. Нажмите **«Открыть сохранённый JSON»**. Приложение повторно читает именно сохранённый
   документ и показывает JSON с единственным верхним ключом `transcript`;
   поля реплик: `speaker_id`, целые `start_ms` / `end_ms`, `text`.
   JSON остаётся доступен в Downloads, его можно открыть другим JSON-редактором
   или скопировать на компьютер через `adb pull /sdcard/Download/jury-transcript.json`.
7. Для повторения выполните Wipe Data AVD и снова шаги 2–6 из этого же комплекта.
   Ручное копирование весов и доступ к каталогам разработчика не требуются.

Это проверка доставки и работоспособности. Синтетическая запись не измеряет
качество на живом диалоге; WER/DER и качество на новых 2/3 голосах здесь не заявлены.
